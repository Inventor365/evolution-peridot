# LUNARIS ROM — RELEASE CHANGELOG (PERIDOT)
**Changes upto November 11th, 2026**

### 1. Hardware
**Dolby**
- Added per-mode Volume Leveler strength control (0–10).

### 2. DT

**Power, Performance & AUTO**
- Refined AUTO app classification with CPU usage validation and dynamic game detection across various engines.
- Improved screen-off power management.
- Reworked Gaming and Performance profile handling with automatic fallback to AUTO after configurable idle timeouts.
- Introduced improved game performance scaling based on measured CPU/GPU load.
- Reworked Battery and Balanced profiles with improved screen-off power management.
- Optimized VoIP, screen sharing and audio playback power handling.
- Added AUTO state reporting, persistent status notification controls and improved profile transitions.
- Refined CPU/GPU frequency limits, WALT tuning, DDR bandwidth prioritization and foreground CPU scheduling.

**Yuki Charging & Battery Care**
- Introduced firmware-backed bypass charging with automatic monitoring and fallback handling.
- Added Night Charging with a dedicated Quick Settings tile.
- Introduced bypass-backed Charge Limit (70–95%) with improved charge isolation and limit enforcement.
- Reworked charging current management for PD, PPS, USB and Superfast charging modes.
- Added consistent temperature throttling across charging modes, including stricter thermal protection.
- Improved charging stability, SOC reporting and cable-connected boot handling.
- Integrated Night Charging status and charging controls into the system UI.

**Audio, Haptics, Sensors & Device**
- Integrated AndromedaHaptics.
- Improved low-latency audio scheduling to reduce speaker crackling and audio underruns in games.
- Added Duck Remote Key Provisioning (RKP) HAL support.
- Optimized sensor notification handling and fixed AOD-related memory leaks.
- Reduced unnecessary vendor audio, sensor and graphics logging.
- Improved USB configuration persistence while restoring ADB and wireless debugging.
- Updated device permissions and wakeup source labeling.
- Refined default application packaging and removed obsolete KProfiles components.

### 3. kernel

**Kernel — SM8635**
- Improved bypass charging and charge-limit handling, reducing unnecessary thermal polling and battery reporting inconsistencies.
- Optimized WALT frequency selection for improved CPU efficiency.
- Fixed haptic effects, primitive composition and input latency.
- Updated ReSukiSU/BakaSU and SUSFS components with SELinux and compatibility fixes.
- Merged upstream LineageOS kernel updates, including Linux 6.1.176 and Qualcomm platform fixes.
- Restored stock voltage and DDR bandwidth configurations at lower GPU frequencies to improve everyday efficiency.
- Fixed Wi-Fi roaming synchronization handling to prevent completed network handoffs from being incorrectly aborted.
